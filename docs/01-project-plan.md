# GPE 題庫計畫

日期：2026-10-27。範圍：將既有 50 份解題檔整理成繁體中文學習網站。

## 使用者需求

- 列出所有題目，點開可讀原文、白話翻譯、解題步驟與程式碼。
- 建議加入題號／名稱／中文關鍵字搜尋、演算法與語言篩選、複雜度及常見陷阱。

## 第一版

完整收錄本 repo 的 50 份解答，不擅自改寫舊程式。所有題目都有依現有程式整理的中文題意摘要、步驟、複雜度與提醒；摘要不是原題逐字翻譯，未核對的限制與來源明確標示。網站提供已能辨識的 UVa 原文連結、按需 PDF 閱讀及無來源時的說明；未取得原文的題目不偽造原文或樣例。

以靜態網站實作，無登入、資料庫、付費服務或後端程式執行。手機與桌面可用；每題有可分享的 hash 網址。

## 後續建議

1. 核對各題來源與原文，確認可收錄範圍後補充完整輸入／輸出規格與手算例子。
2. 建立逐題樣例與邊界測試；舊解答的修復獨立記錄，不覆寫歷史。
3. 視需要新增收藏、複習進度、提示分層與多種解法比較。

## 不在本次範圍

帳號系統、線上執行任意程式，以及宣稱所有舊解答已獲評測通過。GitHub Pages 公開發布已納入使用者後續授權，部署及網站驗證需另外記錄。

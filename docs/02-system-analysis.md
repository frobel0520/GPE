# GPE 題庫需求分析

## 使用案例與驗收

| 需求 | 行為 | 驗證 |
|---|---|---|
| FR-01 全部題目 | 列表恰好涵蓋根目錄全部 C++／Python 解答，各有穩定 ID | 建置／資料測試 |
| FR-02 尋找題目 | 題號、英文、中文與標籤搜尋；語言與演算法篩選可組合；顯示空結果與重設入口 | 瀏覽器互動 |
| FR-03 閱讀題解 | 點題目與直接 hash 連結均可開啟；上一頁／返回列表正常 | 瀏覽器導航 |
| FR-04 內容 | 原文來源區、中文摘要、步驟、複雜度、陷阱與完整程式碼 | 所有題目資料完整性 |
| FR-05 來源誠實 | 原文未核對、來源不明、程式缺陷各有明確區別 | 資料／畫面測試 |
| FR-06 程式碼 | 可閱讀、複製、下載；CP950 舊檔可正確顯示中文 | 原始碼一致性／瀏覽器 |

## 非功能需求

不執行題解程式；不蒐集個資；內容以 textContent 呈現，禁止以原始碼組 HTML。來源 URL 只接受已知官方 HTTPS 網域。支援鍵盤操作、明確焦點、窄螢幕與 reduced motion。站台可置於任意 URL 子目錄，不依賴伺服器路由重寫。無第三方前端套件或 CDN。

## 未決事項

原題網站網路存取目前被拒，所有原文連結尚未完成線上核對；來源不明的題目不能只憑題號接到 UVa。沒有原文時的中文說明僅依舊解答與演算法知識整理，題目的完整限制仍待核對。

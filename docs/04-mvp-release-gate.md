## 來源可信度與後續關卡

先以官方題庫核對題號、題名與實際敘述，再更新中文題意、輸入輸出與手算範例。其他解題文章僅作交叉佐證，不直接當作原題或正確答案。只有取得來源核對證據與日期後才能標示 `originalStatus: verified`；HTTP 200 或檔名相符本身不夠。

原文可採官方閱讀器／連結；若要保存全文，先確認再利用權利。題號不明的題目要確認實際出處，不自動改接同號 UVa。來源核對完成前，本版只可稱為可用的學習網站骨架與歷史解答筆記，不能稱完整題庫已驗收。
